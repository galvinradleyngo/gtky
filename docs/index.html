Gotten to Know You

A live quiz game for testing what you actually know about each other. Everyone joins from their own phone — submit a fun fact, then guess whose fact is whose.

Play Now →

Free hosting means the app may take 30–50 seconds to wake up if it's been idle — open it a minute before you want to start.

How it works

  • Host creates a room and shares a QR code or short link
  • Players join from any device — no accounts needed
  • Rooms can be password protected
  • Guess who each fun fact belongs to; live leaderboard updates as you go
  • Game data is deleted automatically within 2 weeks, sooner on request
